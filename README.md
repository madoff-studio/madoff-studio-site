# Сайт MADOFF studio: инструкция

Обычный сайт на HTML, CSS и JavaScript. Ничего собирать и устанавливать не нужно.

## Что где лежит

| Файл или папка | Что в нём |
|---|---|
| `js/data.js` | **Главный файл для правок:** контакты (Telegram, ВКонтакте), услуги, цены, список работ, «Для кого», «Как работаем», частые вопросы |
| `js/cases.js` | Тексты страниц кейсов: задача, что сделали, технологии, скриншоты |
| `index.html` | Первый экран и заголовки блоков главной |
| `cases/` | Страницы кейсов. Сами страницы пустые, текст берётся из `js/cases.js` |
| `demo/crm/` | Демо мини-CRM для салона |
| `demo/assistant/` | Демо ИИ-ассистента (готовый сценарий ответов) |
| `img/cases/` | Скриншоты и обложки работ |
| `fonts/` | Шрифты Geologica (заголовки) и Inter Tight (текст) с лицензиями OFL |
| `css/style.css` | Оформление. Цвета бренда — в самом начале файла, в блоке `:root` |

## Частые правки

**Поменять Telegram или ВКонтакте:** откройте `js/data.js` и поменяйте строки:
```js
telegram: "raisnop",        // ник без @
vk: "sebastiancoe26",       // адрес после vk.ru/ (если оставить "", кнопка ВКонтакте пропадёт)
```

**Поменять цену:** в `js/data.js`, блок `prices`, поменяйте число в `from`. Пробелы и знак ₽ сайт добавит сам.

**Добавить работу:**
1. В `js/data.js`, блок `cases`, добавьте строку по образцу (придумайте `slug` латиницей, например `shop-bot`).
2. В `js/cases.js` добавьте блок текстов с тем же `slug`.
3. Скопируйте любой файл из `cases/` под именем `shop-bot.html` и внутри поменяйте `data-slug="..."` на `shop-bot`.
4. Скриншоты положите в `img/cases/`.

## Как посмотреть сайт на компьютере

Двойного клика по `index.html` мало: шрифты не загрузятся (так браузер защищает файлы на диске). Нужен локальный сервер, например расширение **Live Server** в VS Code: правый клик по `index.html` → «Open with Live Server».

## Законы РФ — что уже учтено

- Нет форм, аналитики и cookie, поэтому сайт не собирает персональные данные (152-ФЗ). **Если добавите форму заявки или Яндекс Метрику**, понадобятся политика конфиденциальности и согласие на обработку данных.
- Шрифты хранятся на самом сайте, без запросов к Google.
- Тексты на русском языке; иностранные слова заменены там, где есть русский аналог.
- Цены помечены как не публичная оферта (ст. 437 ГК РФ).
- Все работы честно помечены «концепт» или «демо»; салон, клуб и посёлок в работах вымышленные.

## Публикация

Сайт публикуется бесплатно через GitHub и Netlify (адрес вида `madoff-studio.netlify.app`). Каждое изменение, отправленное на GitHub, автоматически появляется на сайте.
